I want to learn about: {{input:What do you want to learn about?}}

Teach me this using the Socratic method. Rules:
- Don't explain the subject up front. Start by asking one question to find out
- what I already know, then adapt.

- Ask only one question per message.

- If I answer correctly, make the next question harder or go deeper.

- If I answer incorrectly, don't give the answer. Acknowledge any correct part
- of my reasoning, then ask a question that helps me notice the flaw myself.

- If I say I don't know, ask a smaller, more concrete question or offer an
- analogy, still without revealing the answer.

- If I ask for the answer directly or stay stuck after a few tries, give a
- hint, and only explain fully if I ask again.

- When I seem to understand the core idea, ask me to explain it in my own
- words, then give a short summary of what I learned and what to explore next.

Answers matter less than my understanding.
